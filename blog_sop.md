# Blog Management Standard Operating Procedure (SOP)

**Author:** Manus AI
**Date:** December 23, 2025

## 1. Introduction

This document provides a standard operating procedure (SOP) for creating, managing, and publishing blog posts for the Atlas AI Insights blog. The goal of this SOP is to ensure consistency, quality, and efficiency in our content production workflow. By following these guidelines, we can maintain a high-quality blog that effectively communicates our expertise in AI, logistics, marketing, and business growth.

## 2. Getting Started: Accessing the CMS

All blog content is managed through Sanity.io, a headless Content Management System (CMS). The Sanity Studio is integrated directly into the Atlas AI Marketing website.

### 2.1. How to Access Sanity Studio

1.  **Navigate to the Studio URL:** Open your web browser and go to [https://www.atlasaimarketing.co/studio](https://www.atlasaimarketing.co/studio).
2.  **Log In:** You will be prompted to log in. Use your designated Sanity.io account credentials (e.g., Google, GitHub, or email/password).

Once logged in, you will see the Sanity Studio dashboard, where you can manage all blog posts.

## 3. Creating and Publishing a New Blog Post

Follow these steps to create a new blog post from start to finish.

### 3.1. Create a New Post

1.  From the Sanity Studio dashboard, click on the **"Post"** document type in the left-hand navigation menu.
2.  Click the **"Create new post"** button (pencil icon) in the top right corner to open a new blog post editor.

### 3.2. Fill in the Required Fields

Each blog post has several required fields that must be completed before publishing. These fields are essential for SEO, content organization, and proper display on the website.

| Field | Description | Instructions |
| :--- | :--- | :--- |
| **Title** | The main headline of the blog post. | Keep it concise, engaging, and relevant to the content. Aim for 60-70 characters. |
| **Slug** | The URL-friendly version of the title. | Click the **"Generate"** button to automatically create the slug from the title. Do not edit this manually unless necessary. |
| **Author** | The author of the blog post. | Select your name from the dropdown list. If you are not listed, contact the administrator. |
| **Category** | The primary category of the blog post. | Select one of the predefined categories from the dropdown list. This is crucial for content filtering on the website. |
| **Published At** | The date the blog post is published. | Use the date picker to select the desired publication date. This field is required for the post to appear on the website. |
| **Main Image** | The featured image for the blog post. | Upload a high-quality, relevant image. Recommended dimensions: 1200x630 pixels. Add descriptive **Alternative text** for SEO and accessibility. |
| **Excerpt** | A short summary of the blog post. | Write a 1-2 sentence summary that entices readers to click. This appears on the main blog page. |
| **SEO Keywords** | Keywords for internal reference and SEO. | Add relevant keywords that describe the main topics of the article. Separate keywords with commas. |
| **Content** | The main body of the blog post. | Write the full article here using the rich text editor. You can format text, add headings, lists, links, and images. |
| **Published** | The toggle to publish or unpublish the post. | **This must be toggled ON for the post to be visible on the live website.** |

### 3.3. Writing and Formatting Content

-   **Headings:** Use headings (H2, H3, H4) to structure your content and improve readability.
-   **Paragraphs:** Keep paragraphs short and focused on a single idea.
-   **Lists:** Use bulleted or numbered lists to break up text and present information clearly.
-   **Links:** Add internal links to other relevant blog posts and external links to credible sources.
-   **Images:** Add images, charts, or diagrams within the content to illustrate your points.

### 3.4. Publishing the Post

1.  **Review:** Once you have filled in all the fields and written the content, carefully review the entire post for any errors or typos.
2.  **Publish:** Click the **"Publish"** button in the top right corner of the editor. The button will turn green and show "Published".

Your blog post is now live! Thanks to the webhook we set up, the website will automatically redeploy, and your new post will appear on the [Insights page](https://www.atlasaimarketing.co/insights) within 1-2 minutes.

## 4. Editing and Updating a Blog Post

To edit an existing blog post:

1.  Navigate to the **"Post"** section in Sanity Studio.
2.  Find the blog post you want to edit in the list and click on it.
3.  Make your desired changes in the editor.
4.  Click the **"Publish"** button again to save your changes. The website will automatically update.

## 5. Deleting a Blog Post

To delete a blog post:

1.  Open the post you want to delete in the editor.
2.  Click the **three-dot menu** in the top right corner.
3.  Select **"Delete"** from the dropdown menu.
4.  Confirm the deletion. The post will be removed from the website on the next deployment.

## 6. Best Practices and Writing Guidelines

To maintain a consistent and high-quality blog, please adhere to the following guidelines:

-   **Tone of Voice:** Professional, authoritative, and helpful. Write for an audience of logistics leaders, marketing professionals, and business executives.
-   **SEO:** Use relevant keywords in your title, headings, and content. Add descriptive alt text to all images.
-   **Readability:** Use short sentences, clear language, and proper formatting (headings, lists, bold text) to make your content easy to read.
-   **Images:** Use high-quality, relevant images that are properly licensed. Optimize images for the web to ensure fast page load times.
